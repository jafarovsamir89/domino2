# Совместная проверка Android после S039

На последней проверке ADB не показал устройство. Play-приложение и его данные не менялись. Теперь есть переносимый сборщик **отдельного** пакета `az.simplesoft.dominotelefon.audit` — исходный debug APK с ID Play использовать не нужно.

## Стенд

1. Из корня запустить `node docs/remediation/scripts/device-review-preview.mjs`. Он слушает только127.0.0.1:4186; API выдаёт синтетические гостевые ответы. Для audit WebView разрешён CORS только с `https://localhost`; проверен отказ постороннему Origin. Production HTTP/WS блокирует CSP. В копии MainActivity исключены GoogleAuth/Browser/DeviceRegion регистрации; опубликованные Android-исходники не меняются.
2. `node docs/remediation/scripts/build-review-apk.mjs`: нужны уже установленные npm зависимости, Android SDK (`ANDROID_HOME` либо local.properties), JDK21 (`JAVA_HOME` либо `.tmp/jdk21/Contents/Home`). Ничего не скачивает через npm install и ничего не устанавливает на телефон. Gradle может получать обычные объявленные Android-зависимости. APK остаётся в `.tmp/mobile-review/...`, переносится через повторную сборку, а не коммит бинарника. [SHA/ID последней сборки](evidence/session-039/review-apk.json).
3. `adb devices -l`; подтвердить отладку на телефоне и выбрать serial. В совместной фазе `node docs/remediation/scripts/install-review-apk.mjs --install --serial DEVICE_SERIAL`: helper проверяет SHA и.audit, устанавливает только отдельный APK, создаёт reverse4186и запускает audit Activity. Без `--install` он только проверяет артефакт. Play не выбирается и не force-stop.
4. На главном экране audit игры нажать «Проверка игры»: откроется локальная панель `https://localhost/review/index.html` внутри audit WebView. Либо в Android Chrome — `http://127.0.0.1:4186/review/index.html`; **Chrome не проверяет Android-политику разрешений WebView**, поэтому R18/R19 проходить также в audit Activity. Если используется CDP вместо кнопки, сначала проверить.audit процесс и метку s039. Не выбирать WebView Play, у него тоже может быть origin localhost.
5. `review/index.html` содержит15карточек, аудиопанель и макеты20/28костяшек. Замороженные макеты не сохраняют resume и не считаются экспериментальными матчами; настоящую партию начать после перезагрузки обычного index. Заметки/решения экспортируютсяJSON, счётчик основного плана не меняется кнопками.

## R15

Выбрать CDP socket только audit процесса (или отдельной Chrome вкладки), пробросить на localhost9229. `node docs/remediation/scripts/startup-device-metrics.mjs --cdp http://127.0.0.1:9229` проверяет s039и loopback endpoints до нажатий/reload. Три значения — текущая навигация и два тёплых reload; это **не cold native launch**.

Зафиксировать модель, OS/WebView, SHA, температуру, сеть, одинаковый режим кеша. Минимум5пар до/после; cold native измерять отдельно после force-stop только.audit. Сопоставимый исходный вариант должен иметь такой же debug/release класс и стенд: сравнение debug с Play release не доказывает ускорение.

Offline: согласованно отключить сеть устройства или явно отличить запрет синтетических запросов. Проверить понятное сообщение, свободную solo, retry после восстановления. ADB reverse может работать при выключенном Wi-Fi: это ещё не доказательство настоящего offline. Не отключать связь владельца без его участия.

## R18/R19/R22/R24

- Микрофон: allow/deny, повтор, отзыв в настройках, отмена диалога, HOME во время ожидания, переход на другой origin. Панель показывает только readyState, не записывает и не отправляет аудио. Затем два разрешённых тестовых клиента и отдельный локальный game/API/TURN стенд: Wi-Fi↔LTE, relay-only, selected candidate pair=relay, двусторонний звук. Гостевой4186preview не является голосовым сервером.
- Звук: master/music/effects, сохранение после force-stop.audit, фон/возврат, настоящий звонок/завершение, Bluetooth connect/disconnect и смена выхода. Chromium остаётся единственным владельцем focus.
- Переводы: AZ/RU/EN экраны/длинные строки/130%шрифт; отдельно носитель TR, неполный язык в live меню не включён.
- Стол:20/28макет, zoom/pan/reset/поворот, затем настоящая партия и оценка читаемости игроком. Снимок/автотест не подменяет мнение игрока.

После работы снять только созданные ADB mappings и вернуть изменённые настройки телефона; не очищать Play данные. Доказательства сохранять новой сессией; S038/S039 исходные результаты не перезаписывать.
