# R-15/R-18/R-19 — что ещё проверить на Android

S038: ADB не показывает устройство. Play-приложение и его данные не изменялись. Собранный debug APK использует опубликованный applicationId: **не устанавливать его поверх Play**. Для нативных проверок подготовить отдельную `.audit` сборку с синтетическим loopback API, как в S021/S022. Старый `.tmp` стенд не переносится через Git.

Переносимый стенд R-15:

1. Из корня `node docs/remediation/scripts/device-review-preview.mjs` — только localhost4186, гостевые ответы, CSP блокирует production.
2. `adb devices -l` — выбрать конкретное устройство; при нескольких командах добавить `-s <serial>`. `adb reverse tcp:4186 tcp:4186`.
3. В отдельной вкладке Android Chrome открыть `http://127.0.0.1:4186/`. Для WebView использовать только изолированный audit package. Не выбирать вкладку/процесс Play.
4. Пробросить CDP выбранного Chrome/audit WebView на localhost9229. `node docs/remediation/scripts/startup-device-metrics.mjs --cdp http://127.0.0.1:9229` проверяет метку стенда и endpoints перед действием; собирает готовность UI и реальное открытие solo-меню. Desktop smoke не является результатом телефона.
5. Для cold/warm сравнения зафиксировать SHA, модель/OS/WebView, температуру, сеть и одинаковый режим кеша; собрать минимум5пар до/после. Cold native launch отдельно измерять после force-stop **только audit package**. Метрики перезагрузки страницы не называть cold запуском приложения.
6. Offline: выключать сеть только по согласованию с владельцем телефона либо отключать запросы в отдельном synthetic стенде. Проверить видимое сообщение, свободную solo, retry после восстановления. Браузерные сценарии уже существуют; реальный offline/native пока не принят.

R-18: на audit WebView проверить allow/deny, отмену permission prompt, background во время ожидания, переход на другой origin, повторный запрос. Java policy tests S038 не заменяют системный диалог. Затем два разрешённых тестовых аккаунта/устройства: Wi-Fi↔LTE и LTE↔Wi-Fi, отдельно relay-only TURN; подтвердить selected candidate pair=relay и двустороннее аудио, не сохраняя TURN credentials в evidence.

R-19: master mute, независимые уровни, force-stop сохранение, HOME/resume уже имеют S021 evidence; S038 устраняет запоздалый configure reply. Осталось проверить настоящий входящий звонок/завершение, Bluetooth connect/disconnect и вывод звука, затем ручной mute до/после возврата. Фокусом владеет Chromium, второй AudioManager не добавлять.
