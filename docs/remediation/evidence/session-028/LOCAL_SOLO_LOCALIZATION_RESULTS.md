# S028 — Гостевая solo и локализация AZ/RU/EN

Дата: 2026-10-19. Локально доработаны R-20 и R-22. Production и опубликованное приложение не изменялись.

## R-20 — бесплатная локальная solo без аккаунта

До изменения гостевая стартовая страница скрывала все игровые кнопки, а обработчик старта solo требовал зарегистрированный аккаунт даже для бесплатной партии. Теперь гость видит только кнопку solo и короткое объяснение: бесплатная игра с ботами доступна без регистрации, онлайн и монетные функции требуют входа.

Бесплатный solo путь не требует токена, не делает лишнее обновление профиля и не посылает гостевой локальный heartbeat в серверное presence API. Проверки аккаунта для онлайн-потоков и для будущего выбора платного solo режима сохранены. Текущая настройка solo остаётся бесплатной.

Статус частичный: `bootstrapAccount` всё ещё должен завершить начальную проверку/таймаут, прежде чем гостю откроется стартовый экран. В этом сеансе не проверяли живой браузер, offline/WebView и фактический экран Android; также не прогоняли сценарии авторизации online. Не считать R-20 полностью принятым.

## R-22 — локализация видимых строк

В AZ/RU/EN добавлены подписи возврата в игру, гостевой подсказки и каталога 12 подарков, включая названия, редкость, количество, пустой список и кнопки магазина/инвентаря. Карточки больше не показывают технические `gift_001`, названия API вида `Gift 001` или значения редкости `common/rare/epic`; сетевой payload и каноническое имя, отправляемое API, не менялись. Для AZ число ботов обозначено `Botların sayı`, для RU — `Количество ботов`.

Статус частичный: это точечный проход по аудиторским примерам, а не гарантия полной локализации всех экранов. Проверка длинных строк на малой ширине, профессиональная вычитка носителями и турецкий pilot не выполнены.
