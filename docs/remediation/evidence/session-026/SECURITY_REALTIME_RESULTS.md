# S026 — допуск в игру и голосовая конфигурация

Дата: 2026-10-19. Ветка `fix/audit-foundation`. Объём: локальная реализация частей R-10 и R-18. Production, опубликованный Play APK, реальные аккаунты и внешние NAT/TURN серверы не затрагивались.

## R-10 — отзыв допуска

Срок нового подписанного game token сокращён с 12 часов до 5 минут для обычного входа и мобильного Google sign-in. Добавлен API `POST /api/platform/game-token/validate`: он проверяет подпись/срок токена, наличие незаконченной API-сессии, связь player с тем же user и отсутствие активной записи player ban. Colyseus вызывает проверку при каждом входе или переподключении; API ответ ограничен 3 секундами. Ошибка/недоступность API закрывает новый вход с временной ошибкой. На каждый ход запросов нет.

Уже вошедший игрок не отключается автоматически после logout/ban/delete: решение о безопасном завершении или передаче хода активной партии не реализовано. Поэтому R-10 остаётся частичным; проверено лишь повторное решение о допуске при следующем входе. API с маршрутом validation должен быть обновлён раньше game server. Ошибка 404 от старой версии API также блокирует новый вход, поэтому rollout требует согласованного порядка.

## R-18 — ICE и разрешение микрофона

`VOICE_ICE_SERVERS_JSON` теперь принимает одиночный URL строкой, массив URL или прежний объект `urls`; разрешаются только схемы `stun:`, `stuns:`, `turn:` и `turns:`. Поле `hasTurn` учитывает `turns:`. Клиент root и `www` одинаково нормализует строку и массив. Android разрешает аудиозапись только origin `https://localhost` (локальная Capacitor-страница) и `https://gamed.simplesoft.az`; другой протокол/host/порт отклоняется. После системного диалога разрешение выдаётся лишь если WebView всё ещё на исходном доверенном origin. Ожидающий запрос отклоняется при закрытии Activity.

Проверки этой сессии: root source check прошёл; `node --check` для server index и DominoRoom прошёл; TypeScript API проверка `tsc -p tsconfig.json --noEmit` прошла; `git diff --check`, валидатор плана аудита и все347 хешей манифеста прошли. Android Gradle compile не завершился: на компьютере доступен только JDK 17, проект требует Java 21 (`invalid source release: 21`). Первоначальный прямой `./gradlew` также не имел права запуска; запуск через `bash gradlew` дошёл до компиляции и выявил несовпадение JDK.

Функциональные тесты не запускались. Нет проверки реального запроса микрофона на телефоне и нет двухсети/операторского ICE, relay-only TURN или NAT результата. Не считать R-10/R-18 полностью принятыми.

## Следующие действия

1. После доступности JDK 21 пересобрать Android debug target и проверить доверенный/недоверенный origin, отказ и смену страницы во время диалога.
2. В локальной синтетической среде проверить валидную, отозванную, истёкшую, заблокированную и удалённую сессию на API/game-server join boundary.
3. Решить контракт для уже начавшейся партии после logout/ban/delete; сохранить закрытие settlement и reconnect state.
4. Проверить STUN/TURN на двух клиентах через Wi-Fi и LTE, включая relay-only. До такого прогона обещание связи через мобильный NAT отсутствует.

Простыми словами: новый вход в игру теперь сверяет, что аккаунт ещё действует и не заблокирован; настройка STUN больше не теряет адрес, а разрешение микрофона не уходит посторонней странице. Уже начатая партия и настоящая мобильная сеть требуют отдельной проверки.
