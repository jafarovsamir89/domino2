## Результат

Три настоящих сообщения Test callback из кабинета LevelPlay прошли проверку подписи/синтетического идентификатора и получили origin HTTP200 за8.460125/6.035792/9.188917мс. Нет Origin, user-agent не браузерный; ошибок CORS в браузере не обнаружено. Это время обработчика, не полная задержка доставки или доказанный лимит провайдера. Кабинет продолжает сообщать invalid configuration.

Первоначально внешний HTTPS-ответ был gzip/chunked без Content-Length. Минимальная правка только signature-only probe задаёт точную длину в байтах и Cache-Control:no-store,no-transform. После неё внешний ответ XML имел длину43, plain26; без сжатия/chunking, тело совпадает. Обе формы всё ещё отвергнуты кабинетом. Изменение делает транспорт предсказуемым, но причина отказа не установлена. Plain доступен через `--plain-ack`, default остаётся XML. Диагностика сохраняет только формы полей, классификацию Origin/UA, время и статус, без значений ключей/подписей/nonce.
