# S039 — результаты по оставшимся 15 карточкам

21 октября 2026. Ветка `codex/remaining-fifteen`, база b10a51e.

Выполнены доступные локальные исправления и подготовка всех 15 оставшихся карточек перед совместной проверкой. **Это не 15 полных закрытий. Основной счёт остаётся 27/42.** Телефон, реальные сервисы, права на материалы, решения владельца и сравнение реальных пользователей остаются условиями плана.

## Проверки

- Полный `npm test`: **433/433 server + 155/155 API**, без падений и пропусков. Проверка синтаксиса входит в команду.
- Полный Playwright: **85/85**, без падений и пропусков. Новые 8 сценариев проверяют полный игровой экран, локальный первый запуск и настоящие черновые кадры для магазина. Дополнительно прошли 20 проверок локализации/геометрии после затемнения; после финального расширения состояний приглашений и окна монет — 17 проверок локализации/обзора и повтор 433 серверных тестов.
- [Настоящая локальная PostgreSQL](rewarded-local-db.json): 100 подтверждений / одна награда; повтор после нового подключения не начисляет снова; искусственный сбой откатывает wallet/daily/receipt/attempt; отмена, просрочка и чужая повторная транзакция отклоняются. Сверка монет: остаток расхождения 0; резерв не меняется. Указанная провайдером сумма 99 999 не выбирает размер награды.
- Java 21: `testDebugUnitTest assembleDebug` успешно; две проверки политики микрофона. `aapt` подтверждает пакет `az.simplesoft.dominotelefon.audit`. [Размер и SHA APK](review-apk.json). APK не установлен.
- [Панель](review-panel-smoke.json): 15 карточек, выгрузка решений, настоящий guided start, макет 28 костяшек и аудионастройки — успешно, ошибок страницы нет. Размеры текстур проверены браузером; это не измерение настоящей GPU-памяти Android.
- Реестр прав проверяется генератором. Root/www: совпадают 24 пары исходников и index. Старые снимки S038 после тестов восстановлены; новые результаты хранятся в S039.
- Три измерения запуска в браузере — только проверка инструмента. ADB сейчас пуст. Зелёный CI предыдущего пакета не объявляется CI этого нового кода.

## Совместная проверка

Из корня запустить `node docs/remediation/scripts/device-review-preview.mjs`, открыть `http://127.0.0.1:4186/review/index.html`. Заметки сохраняются только в этом браузере и выгружаются JSON. Они не закрывают карточки плана автоматически.

Android: `node docs/remediation/scripts/build-review-apk.mjs` — нужны JDK 21, Android SDK и уже установленные зависимости. В совместной фазе: `node docs/remediation/scripts/install-review-apk.mjs --install --serial DEVICE_SERIAL`. Без `--install` helper только проверяет файл. Он проверяет `.audit` и SHA, не выбирает пакет Play. Подробности: [DEVICE_ACCEPTANCE_NEXT](../../DEVICE_ACCEPTANCE_NEXT.md).

Порядок: телефон (R15/R18/R19/R22/R24) → два клиента (R35) → решения R21/R33 и права R30 → оператор/реальный SSV (R09/R28/R36) → носители/материалы R37/R38 → согласованные реальные группы R34/R35/R36/R37. Одного телефона недостаточно для всех двухсторонних и статистических проверок.

Работающий сервер, живые данные и пакет Play не менялись. Плагины Codex не устанавливались, работа другим агентам не делегировалась. Локальные варианты выключены вне явно включённого тестового стенда.
