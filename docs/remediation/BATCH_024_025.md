1. **R-29 — итог с монетами сохраняется до отправки.** Если API завис или игровой сервер остановился, после запуска он повторит доставку. Повтор не начисляет монеты второй раз. Проверено на отдельной базе с настоящей остановкой процессов, потерей ответа и20дублями. Перед будущим выпуском нужна постоянная папка на сервере, переживающая его замену; [требования](evidence/session-024/OUTBOX_OPERATIONS.md). Production не обновлялся.
