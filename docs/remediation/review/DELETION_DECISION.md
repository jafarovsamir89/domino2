# R21 — конкретный проект для обсуждения

Владелец отложил политику удаления21октября. Ничего ниже не считается утверждённым и не запускает удаление. Существующий profile→mailto и webrequest остаются; delivery/оператор пока не подтверждены.

Предлагаемый процесс: запрос в профиле или web→подтверждение владения учётной записью без запроса пароля/токенов по email→номер запроса и квитанция→оператор проверяет активные матчи/резервы/платежи→предварительный dry-run удаления/обезличивания по согласованной карте→подтверждённая атомарная операция в БД→очередь внешних провайдеров→сообщение о результате и отдельно о законно сохраняемых категориях→проверка восстановления backup, исключающая возврат удалённого профиля.

Для следующего совместного шага:

| Решение | Варианты для обсуждения, без выбранного default |
|---|---|
| Исполнитель/доставка | Конкретный ответственный и реально проверенный inbox; резервный ответственный |
| Подтверждение заявителя | Недавний повторный вход в приложении; безопасный одноразовый webпуть для удаливших приложение |
| Данные профиля | Удалить/обезличить профиль, аватар, authсвязи, сессии, pushтокены и внешние аватар/файлы |
| Чаты/голос/приглашения | Удалить вложения и определить судьбу сообщений у собеседника, потоков и последнего сообщения |
| Результаты/рейтинг | Сохранить обезличенный итог либо удалить; обязательно обработать name snapshots, а не только PlayerFK |
| Монеты/платежи/жалобы | Определить обоснованный состав/сроки хранения; не разрушить расчёты других игроков и общий ledger |
| Backup/провайдеры | Сроки/владельцы/подтверждение удаления; план restoreи повторного применения deletionmarkers |
| Сроки и тексты | Реальные сроки исполнения/уведомления/эскалации; затем согласованно обновить privacy/web/Console |

Карта фактической схемы: `../evidence/session-039/deletion-schema-map.json`. AdminAuditLog связан CascadeсUser: удаление админского Userможет уничтожить audittrail. Не применять genericdeleteкPlayer/Userбез отдельного процесса. Нужен dry-runна синтетических данных и проверки повторного запроса/rollback/сохранности чужого матча после утверждения политики; текущая карта не подменяет такой тест.
