Первый запуск — локальный вариант

Бесплатная solo без аккаунта. Выберите правила, начните партию и попробуйте ещё раз после результата. Монеты для бесплатной solo не нужны.



Решение о монетах (R33)
Текущая серия: 5 050 / 51 050 / 171 050 монет за 7 / 30 / 90 дней. Повтор недели: 5 050 / 20 700 / 63 650. Это расчёт defaults кода, а не реальные кошельки. Выбор ниже не меняет выдачу.


Удаление аккаунта (R21)
Нужны решения по исполнителю, подтверждению заявителя, срокам, чатам, результатам матчей, платежам, резервным копиям и внешним провайдерам. Удаление User само по себе оставляет Player и часть текстовых данных.


Косметика — только предпросмотр (R38)
Два существующих стола, без покупки, монет и изменения правил. Права ещё должны быть подтверждены владельцем.
