## Аннотации к проблемным зонам

**U1 / R-20 — первый запуск.** На screenshot 01 центральная карточка требует аккаунт прежде знакомства с игрой. Для человека, ищущего offline домино, это ранний барьер. Предложение: «Попробовать с ботом» с локальным профилем, а регистрацию объяснять сохранением рейтинга и online. Не выдавать гостю онлайн-кошелёк без серверной identity. Измерить install→first legal move и auth abandonment.

**U2 / R-22 — локализация.** Внизу login card строка «Sign in to continue» остаётся английской; на screenshot 07 название, цена `coins` и русские CTA перемешаны. Разнести translatable text и brand names; plural/number/date форматировать locale. Турецкого языка в selector нет: интерес к TR надо сначала проверить локализацией, не рекламой. Проверить AZ/RU/EN с длинными именами и Turkish glyphs.

**U3 / R-23 — касания.** В [ui-capture.json](evidence/metrics/ui-capture.json) записаны реальные размеры controls: часть верхних icon buttons около 34 px, менее удобного touch target. Ориентир продукта — 48dp для ключевых Android действий; можно расширить hit area без увеличения видимого значка. Для hand вмещать 7 костяшек и использовать enlarged drag preview/выбор конца, а не уменьшать все клики до 28 px. Близкие цели должны иметь достаточный зазор.

**U4 — social header screenshot 05.** Слева заголовок усечён, справа wallet/rating/headphones/close. Перенести balance в shop/profile, оставить контекст и close; дать tabs «Друзья / Чаты / Приглашения». Польза — найти человека и понять unread, а не показать всю экономику в одной строке. Chat/invite/gift acceptance states с двумя живыми профилями не пройдены полностью, поэтому их качество не оценивается как проверенное.

**U5 — настройки screenshot 03.** Число 255 выглядит как системный input и не объясняет, что означает. Добавить одну короткую подпись и presets, расширить switch target. Настройка 35 должна соответствовать фактическому правилу после R-08; хороший дизайн не исправляет неверную логику.

**U6 / R-24 — стол.** Ковровый стиль создаёт региональный характер, но высокая детализация под мелкими точками затрудняет сканирование. Сохранить его по краям; центр сделать спокойнее или добавить мягкую однородную подложку под поле. Не связывать это с FPS: один flat-background A/B почти не улучшил rAF. Польза здесь — читаемость. Нужны zoom/reset и просматриваемый preview костяшки, не уменьшать текст счёта при 4 игроках.

**U7 — open rooms screenshot 10.** Золотые chips одновременно выделены, значение состояния фильтра неочевидно. Активный filter должен иметь отдельный selected indicator/aria-pressed, другие — нейтральные. Заголовок сокращать до «Комнаты», сохранить create CTA. Empty state: сбросить фильтры / создать / пригласить друга; показывать online count только по достоверному presence.

**U8 — profile/shop.** В screenshot 04 профиль быстро превращается в каталог; stats и история должны быть доступны без прокрутки коллекции. В screenshot 06 пока отключена покупка, достаточно компактного wallet/history вместо полноценного пустого магазина. В screenshot 07 повтор «Выбрано» три раза не помогает — один badge и disabled CTA.

**U9 — ошибки / reconnect.** Должны объяснять фазу: «Связь потеряна, место сохранено …», «Матч завершён …», «Не удалось подтвердить результат …». Не показывать локальный countdown как обещание сервера; deadline приходит от сервера. Успешный reconnect не должен закрывать summary уже завершённого матча. Полный визуальный набор offline/server-error states остаётся задачей приёмки.

## Доступность

Измерений контраста всех токенов WCAG нет, поэтому числовые fail ratios не выдумываются. Визуальные кандидаты: мелкий copyright, dim labels, золотой текст поверх орнамента. Проверить TalkBack labels для icon-only controls, logical focus order, dialog focus trap/restore, scaling font 130/200%, reduced motion, mute state и цветонезависимую индикацию игрока/очков. Canvas требует параллельного доступного списка руки и вариантов хода: прозрачные DOM anchors сами по себе не доказывают доступность.

## Три направления с пользой

1. **Спокойный стол:** региональная фактура по краям, спокойный центр, отчётливые ходы, статический свет текущего игрока. Цель — читать поле при 20+ костяшках и снизить стоимость эффектов.
2. **Быстрый матч:** локальный solo за одно действие, объяснение правила на первом ходе, один rematch CTA и ясный итог. Цель — сократить время до первого удовольствия.
3. **Домино с друзьями:** крупные аватары/имена, один invite/share code, приватность, опциональный voice, честно помеченный AI. Цель — завершить совместную партию без технических настроек.

Сохранять золото/тёмный фон и визуальный характер, проверяя каждое изменение на задаче: найти ход, пригласить человека, прочитать результат. Новая тема без улучшения этих действий не приоритет.

## Звук

`js/sounds.js:249–259` mute меняет громкость музыки, SFX не проверяют этот флаг. Контролируемый probe после muted=true запустил три oscillator в sndScore. Пользовательская кнопка «Вкл/Выкл звук» обещает больше, чем реализует. Нужны отдельные music/effects/voice, общий master mute, сохранение prefs, audio focus и pause в background.

Синтез clack/score не требует сетевого decode, но задержка физического звука и качество динамика не измерялись. Тестировать перекрытие трёх score/reaction/gift событий, звонок, Bluetooth и другую музыку. Для MP3/art assets в изученных файлах не найден реестр происхождения/лицензий; это пробел доказательств прав, а не утверждение о нарушении. Внести источник, право на коммерческое распространение, автора и требования attribution для каждого asset.
