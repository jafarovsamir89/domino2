## Этап 3 · 🟡 Решения по монетизации

### 3.1 Покупка монет

- [ ]  Принять решение: продаём монеты или нет
- [ ]  Если ДА → интегрировать **Google Play Billing** (клиент + верификация покупки на сервере через `Order`/`Payment`/`PaymentEvent`)
- [ ]  Если ДА → подключить каталог товаров (`CatalogProduct`/`CatalogPrice`) и выдачу монет через идемпотентный леджер
- [ ]  Если НЕТ → убрать из UI любые намёки на «покупку монет» (`getCoinShopStatus` возвращает пусто)

### 3.2 Реклама / видео-награда

- [ ]  Принять решение по `economy/coin-shop/video-reward` и `daily-bonus rewarded_x2`
- [ ]  Если реклама НУЖНА → подключить AdMob + server-side verification (SSV), связать с `ad_reward`
- [ ]  Если НЕТ → убрать «видео-награду»/`rewarded_x2` из UI и эндпоинтов (чтобы не вводить в заблуждение на ревью)

### 3.3 Пуш-уведомления (FCM)

- [ ]  Принять решение: нужен ли пуш в первом релизе
- [ ]  Если ДА → добавить `google-services.json`, довести клиентский флоу + `firebase-admin` отправку
- [ ]  Если НЕТ → убрать `@capacitor/push-notifications` из сборки
